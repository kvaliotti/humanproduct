# Plain writing rules

These apply to every strategic-research file. The reader is a busy product lead who is new to this market.

- Short sentences. One idea each. If a sentence needs rereading, rewrite it.
- Plain words. No framework names, acronyms, or invented labels in the output. Say "hard to copy because customers' data lives there", not "switching-cost power".
- Name real things: companies, products, prices, numbers, job titles. Never "various tools" or "many companies".
- Every fact gets a source: a link in the **Sources** list, cited inline as [1], [2]. If there's no source, write **(assumption)** after it.
- No scores, percentages, or ratings you made up. Use Strong / OK / Weak or High / Medium / Low only when the reason is written next to it.
- Tables for comparisons, bullets for lists, prose only for the conclusion.
- Each file is at most 2 pages. Cut before adding. If something doesn't change what we'd do, delete it.
- End every file with **What we don't know**: the 3 gaps that matter most and how to close each (who to ask, what to check).
