# plg-growth

Product-led growth help for product managers. Each skill answers the question briefly by default and runs the full analysis only when you ask for it. Every number comes from your own data or a named source. There are no invented benchmarks or scorecards.

Start with **plg-orchestrator** if you're not sure where to begin. It asks a few questions and points you to one skill.

| Skill | Use it when |
|---|---|
| `plg-orchestrator` | You want PLG help and don't know where to start |
| `plg-readiness` | You're deciding whether PLG fits, and whether your free experience proves what buyers decide on |
| `plg-revenue-analysis` | You want to know which revenue lever to pull and what it's worth |
| `acquisition-model-selector` | You're choosing freemium, free trial, reverse trial, ungated, or a demo |
| `acquisition-domain` | You need more of the right signups: channels, product-driven SEO, sidecar tools, piggybacking |
| `activation-domain` | Users sign up but don't reach first value |
| `retention-domain` | Users reach value but don't come back |
| `monetisation-domain` | Users stay but don't pay or expand |
| `satisfaction-domain` | You're working on NPS/CSAT, advocacy, or the PMF survey |
| `growth-loops` | You're designing viral, content, paid or sales loops |
| `product-led-sales` | You need PQLs, sales-assist triggers, or land-and-expand |
| `plg-experimentation` | You're designing or prioritising experiments |
| `plg-data-setup` | You can't measure your funnel yet |
| `plg-transformation` | Org, incentives or team structure are blocking PLG |

Shared rules every skill follows live in `references/problem-solving-backbone.md`.
